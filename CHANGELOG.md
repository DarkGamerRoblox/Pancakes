# Changelog

All notable changes to Pancakes will be documented here.

## 1.1.0 - 2026-09-27

- Expanded Auto and Schema support for Roblox datatypes, buffers, sequence keypoints, and nested containers.
- Added decode safety limits for buffer bytes, sequence keypoints, and Instance path depth.
- Improved Auto and Schema speed and wire size for repeated record payloads.
- Added full type coverage and comparative benchmark documentation.

## 1.0.0 - 2026-09-07

- Initial Pancakes release.
- Auto, Schema, and SmartSchemas serialization modes.
- Roblox datatype support.
- Custom converters and directory helpers.
- Runtime pooling/caching configuration.
- Strict malformed-buffer checks and schema validation defaults.
