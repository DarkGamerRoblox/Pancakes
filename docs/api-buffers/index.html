API reference

Buffer utilities

Measure and copy buffers, inspect bytes, and understand the limitations of the text helpers.

2 min readRoblox Luau

GetSize#

Return the buffer length in bytes. Equivalent to buffer.len(buf).

Signature
Luau
Pancakes.GetSize(buf: buffer): number

CloneBuffer#

Copy all bytes into a newly allocated buffer.

Signature
Luau
Pancakes.CloneBuffer(buf: buffer): buffer

Mutating the copy does not change the original.

ConcatBuffers#

Copy the buffers into one buffer in array order.

Signature
Luau
Pancakes.ConcatBuffers(buffers: {buffer}): buffer
Concatenation does not frame messages

This function adds no lengths, offsets, or message count. A deserializer will not automatically split concatenated payloads. Use SerializeBatch or add an explicit framing protocol.

CompareWithJSON#

Compare HttpService:JSONEncode byte length against the default SmartSchemas Serialize output.

Signature
Luau
Pancakes.CompareWithJSON(data: any): {
    jsonSize: number,
    binarySize: number,
    improvement: number,
    improvementPercent: number,
}

Input must be JSON-encodable. Improvement is JSON bytes minus binary bytes, so negative values mean the binary payload is larger. The percentage is rounded down. This is a size comparison, not a time benchmark; repeated calls can affect global SmartSchemas promotion state.

ToHex#

Encode each byte as two lowercase hexadecimal characters.

Signature
Luau
Pancakes.ToHex(buf: buffer): string
Hex round trip
Luau
local encoded: buffer = Pancakes.SerializeAuto({ coins = 5 })
local text: string = Pancakes.ToHex(encoded)
local restored: buffer = Pancakes.FromHex(text)
assert(buffer.tostring(restored) == buffer.tostring(encoded))

FromHex#

Decode pairs of hexadecimal characters into bytes.

Signature
Luau
Pancakes.FromHex(str: string): buffer

This implementation drops a trailing odd character and substitutes zero for invalid pairs. Validate that external input has even length and contains only hexadecimal characters before calling it.

Validate text input
Luau
local function decodeHex(text: string): buffer
    assert(#text % 2 == 0, "Hex must have an even length")
    assert(string.match(text, "^[%da-fA-F]*$") ~= nil, "Invalid hex")
    return Pancakes.FromHex(text)
end

ToBase85 / FromBase85#

Signatures
Luau
Pancakes.ToBase85(buf: buffer): string
Pancakes.FromBase85(str: string): buffer

Intended as compact text representations of binary data. The current implementation mishandles partial groups and repeated zero-group output can exceed its decode allocation. Treat these helpers as requiring correction before use.

ToBase91 / FromBase91#

Signatures
Luau
Pancakes.ToBase91(buf: buffer): string
Pancakes.FromBase91(str: string): buffer

Intended as Base91 text helpers. The decoder does not retain the residual bit accumulator needed between symbol pairs, so arbitrary multi-byte round trips are not reliable in this build. It also skips unknown input characters.

Use raw buffers or validated Hex for this build

Encoding is not encryption. These utilities provide no confidentiality, authentication, or message framing.
