API reference

Directories

Represent frequently used string identifiers with shared numeric IDs.

2 min readRoblox Luau

RegisterDirectory#

Register a named lookup and construct its reverse name-to-ID map.

Signature
Luau
Pancakes.RegisterDirectory(
    name: string, idToName: {[number]: string}
): ()

Directory fields encode IDs as unsigned 16-bit integers. Use unique names and integer IDs in 0…65535. The implementation does not comprehensively validate those constraints; define and validate mappings in your shared configuration.

Shared item directory
Luau
Pancakes.RegisterDirectory("Items", {
    [1] = "Honey",
    [2] = "Wax",
    [3] = "RoyalJelly",
})

local schema: Pancakes.Schema = {
    Pancakes.Field.Directory("id", "Items"),
    Pancakes.Field.U32("amount"),
}

local encoded: buffer = Pancakes.SerializeSchema({
    id = "Honey",
    amount = 12,
}, schema)
local item = Pancakes.DeserializeSchema(encoded, schema)
assert(item.id == "Honey")

Directory dictionary keys#

Encode known item names as keys
Luau
local schema: Pancakes.Schema = {
    Pancakes.Field.Dictionary(
        "items",
        Pancakes.Field.U32(""),
        "directory",
        "Items"
    ),
}

local encoded: buffer = Pancakes.SerializeSchema({
    items = { Honey = 12, Wax = 4 },
}, schema)

Mapping lifetime#

Mappings are part of the wire contract

The same numeric ID must mean the same string on every writer and reader. The payload does not ship the directory mapping. Renumbering existing entries changes meaning.

Registration retains the supplied ID-to-name table, while constructing a separate reverse map. Do not mutate the original table afterward. Already-compiled codecs can cache a directory lookup; avoid hot-swapping registrations. Unknown names on write or IDs on read throw.
