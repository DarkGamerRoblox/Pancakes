Field constructors

Compose schemas with Pancakes.Field. Constructors describe the layout; application code still validates its values.

3 min readRoblox Luau

Primitive and Roblox fields#

These constructors take a single name: string and return SchemaField<T>. Example: Field.U16("level"). Sizes below describe field data, not the full payload or its headers.

ConstructorValue typeRepresentation
Field.U8(name)number0…255; 1 byte
Field.I8(name)number−128…127; 1 byte
Field.U16(name)number0…65535; 2 bytes
Field.I16(name)number−32768…32767; 2 bytes
Field.U32(name)number0…4294967295; 4 bytes
Field.I32(name)number−2147483648…2147483647; 4 bytes
Field.U64(name)numberUnsigned 64-bit representation; Luau number precision still applies
Field.I64(name)numberSigned 64-bit representation; Luau number precision still applies
Field.F32(name)number32-bit float; precision can be lost
Field.F64(name)number64-bit float
Field.AdaptiveNumber(name)numberValue-dependent numeric encoding
Field.Boolean(name)booleanBoolean value
Field.String(name)stringLength-prefixed byte string
Field.Vector3(name)Vector33 float32 components
Field.Vector3Int(name)Vector33 signed 16-bit components; decodes to Vector3
Field.Vector2(name)Vector22 float32 components
Field.Vector2Int(name)Vector22 signed 16-bit components; decodes to Vector2
Field.CFrame(name)CFramePosition and full rotation matrix as float32

Integer vectors are still vectors

Field.Vector3Int returns a Vector3 field, not Vector3int16. Its components must fit a signed 16-bit integer. Use Field.Auto if the actual Vector3int16 datatype must be preserved.

Field.Optional#

Return a shallow clone of a descriptor with optional = true.

Signature
Luau
Field.Optional<T>(field: SchemaField<T>): SchemaField<T?>

The original descriptor is unchanged. An absent field decodes to nil; nested definitions remain shared.

Example
Luau
Field.Optional(Field.String("nickname"))

Field.Table#

Describe a nested named record using another ordered schema.

Signature
Luau
Field.Table<T>(name: string, subSchema: Schema): SchemaField<T>
Example
Luau
Field.Table("stats", {
    Field.U16("level"),
    Field.U32("xp"),
})

Field.Array#

Describe a dense array. The element descriptor controls how each entry is encoded.

Signature
Luau
Field.Array<T>(
    name: string, element: SchemaField<T>
): SchemaField<{T}>
Example
Luau
Field.Array("tags", Field.String(""))
Field.Array("items", Field.Table("", itemSchema))

Use an empty element name for clarity. For absent positions, prefer dense slot records with an optional value rather than holes.

Field.Dictionary#

Describe string-keyed values. keyType defaults to "string".

Signature
Luau
Field.Dictionary<T>(
    name: string,
    value: SchemaField<T>,
    keyType: ("string" | "directory")?,
    directoryName: string?
): SchemaField<{[string]: T}>

When keyType is "directory", directoryName is required and keys use that registered name-to-ID mapping. Numeric dictionary keys are not supported by this constructor.

Example
Luau
Field.Dictionary("counts", Field.U32(""))
Field.Dictionary("items", Field.U32(""), "directory", "Items")

Field.Enum#

Describe an EnumItem of a named Roblox enum type.

Signature
Luau
Field.Enum(name: string, enumType: string): SchemaField<EnumItem>

Pass the type name string without Enum.. Validate that input values belong to that enum.

Example
Luau
Field.Enum("material", "Material") -- Enum.Material.Plastic, etc.

Field.Directory#

Encode a registered string name using its 16-bit directory ID.

Signature
Luau
Field.Directory(name: string, directoryName: string): SchemaField<string>

Register the directory first and preserve its mapping across readers and writers. Directory reference.

Example
Luau
Field.Directory("id", "Items")

Field.Custom#

Use a converter registered for the supplied metatable.

Signature
Luau
Field.Custom(name: string, classMetatable: {any}): SchemaField<any>

Register the converter before compilation. Its write/read callback becomes the field codec. Converter reference.

Cross-VM schema hash caveat

This build hashes tostring(classMetatable) into a custom field’s schema version. Ordinary table identity strings differ across VMs; do not assume separately compiled custom schemas are compatible.
