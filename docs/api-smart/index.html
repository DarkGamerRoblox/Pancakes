API reference

SmartSchemas

Track repeated shapes locally, promote them into schemas, and optionally encode deltas.

3 min readRoblox Luau
Local state is part of this format

A fresh receiver cannot reconstruct promoted schemas from the buffer. Receiving Auto messages does not populate its promotion registry. Use Auto or explicit shared Schema for independent peers and durable data.

NewSmartSchemas#

Create an independent SmartSchemas object with its own shape and delta state.

Signature
Luau
Pancakes.NewSmartSchemas(
    config: Pancakes.SmartSchemaConfig?
): Pancakes.SmartSchemas
Config keyDefaultBehavior
promotionThreshold20Number of serialization sightings before promotion. Required when you pass a config table.
deltaKeyframeInterval64Optional full-state cadence for promoted, ID-based streams.

Use positive integers for these values. The constructor takes the provided configuration as-is instead of merging partial defaults.

Example
Luau
local smart = Pancakes.NewSmartSchemas({
    promotionThreshold = 20,
    deltaKeyframeInterval = 64,
})

smart:Serialize#

Serialize through this object. Without promotion, output is tagged Auto; promoted tables use Schema, or Delta when an ID is present.

Signature
Luau
smart:Serialize(
    data: any, disableTracking: boolean?, id: (string | number)?
): buffer

Pass true for disableTracking to skip learning and promotion for that call. Output still has the SmartSchemas envelope. Empty tables and non-table values also use tagged Auto.

smart:Deserialize#

Decode tagged Auto, Schema, or Delta output.

Signature
Luau
smart:Deserialize(buf: buffer, id: (string | number)?): any

Promoted formats require the schema in this object’s registry. Delta decoding requires the same ID and previous state. Consume every dependent message in order. Delta results are shallow clones, so nested tables may share state; treat decoded delta values as read-only or copy before mutation.

Same-instance example
Luau
local smart = Pancakes.NewSmartSchemas({ promotionThreshold = 2 })

for coins: number = 1, 4 do
    local encoded: buffer = smart:Serialize({ coins = coins }, false, "player-1")
    local decoded = smart:Deserialize(encoded, "player-1")
    assert(decoded.coins == coins)
end

smart:GetShapeStatus#

Return whether the matching shape is promoted, followed by its serialization sighting count.

Signature
Luau
smart:GetShapeStatus(data: {[string]: any}): (boolean, number)

Unknown or empty shapes return false, 0. This query does not add a sighting.

Example
Luau
local promoted: boolean, sightings: number =
    smart:GetShapeStatus({ coins = 100 })

smart:ForceFullDelta#

Clear send/receive delta state for the ID across known schema versions.

Signature
Luau
smart:ForceFullDelta(id: string | number): ()

The next promoted serialization for that ID writes a full state. This does not teach a schema to a new instance.

smart:Reset#

Clear learned shapes, compiled schemas, and all delta state.

Signature
Luau
smart:Reset(): ()

Configuration is preserved. Promoted buffers from before the reset are no longer independently decodable through the cleared registry.

Global wrappers#

Pancakes.GlobalSmartSchemas is a SmartSchemas object created when the module loads. These module functions delegate to it:

Global API
Luau
Pancakes.Serialize(data: any, disableTracking: boolean?, id: (string | number)?): buffer
Pancakes.Deserialize(buf: buffer, id: (string | number)?): any
Pancakes.ForceFullDelta(id: string | number): ()
Pancakes.ConfigureSmartSchemas(config: Pancakes.SmartSchemaConfig): ()
Pancakes.ResetSmartSchemas(): ()

ConfigureSmartSchemas replaces the global object’s configuration; it does not reset learned state. It does not configure independent objects created by NewSmartSchemas.

Inference limits#

  • CFrames promote to CFrameSimple in this build, which does not preserve arbitrary roll. Choose an explicit Field.CFrame schema for full rotation.
  • Integral vectors promote to signed-16-bit vector fields. Keep components in range or use an explicit float-vector schema.
  • Shape keys are converted to strings. Avoid mixing keys such as numeric 1 and string "1", or non-string/non-number keys.
  • Do not retain promoted output for a later boot. Schema and delta registries are not persisted.
