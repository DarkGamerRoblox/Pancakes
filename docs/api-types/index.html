Exported types

Luau type aliases and callback interfaces exposed by the Pancakes module.

2 min readRoblox Luau

Core types#

ExportMeaning
SerializedDatabuffer; returned by serialization methods.
SerializerConfigRuntime settings type exported through the Settings module.
SchemaFieldTypeString union of the supported schema codec identifiers.
SchemaField<T>Named field descriptor carrying codec options and a phantom value type.
Schema{SchemaField<any>}; an ordered list of field descriptors.
CompiledSchemaCached compiled plan. Treat its internal fields as opaque.
DirectoryLookupA lookup with toId: {[string]: number} and toName: {[number]: string}.
SmartSchemaConfigPromotion threshold and optional delta keyframe interval.
SmartSchemasMethods for Serialize, Deserialize, GetShapeStatus, ForceFullDelta, and Reset.
Writer / ReaderBorrowed binary I/O interfaces used by converter callbacks.
ConverterWriteFn / ConverterReadFnCustom encoding and reconstruction callbacks.

SchemaField structure#

Descriptor shape
Luau
export type SchemaField<T = any> = {
    name: string,
    type: SchemaFieldType,
    optional: boolean?,
    enumType: string?,
    directoryName: string?,
    schema: {SchemaField}?,
    element: SchemaField?,
    keyType: ("string" | "directory")?,
    value: SchemaField?,
    customMetatable: {any}?,
    _phantom: T?,
}

Prefer Pancakes.Field constructors to hand-authoring descriptors. The phantom type improves descriptor annotations; DeserializeSchema itself returns {[string]: any}, not an inferred application record.

Writer and Reader methods#

These interfaces are passed into converters. There is no public Pancakes.Writer.new or Pancakes.Reader.new export. Use colon syntax and keep reads paired with writes.

WriterReaderPurpose
WriteBits(value, bits)ReadBits(bits)Bit-level unsigned value.
WriteU8 / WriteU16 / WriteU32 / WriteU64ReadU8 / ReadU16 / ReadU32 / ReadU64Unsigned integer values.
WriteI8 / WriteI16 / WriteI64ReadI8 / ReadI16 / ReadI64Signed integer values; there is no public WriteI32 method.
WriteF32 / WriteF64ReadF32 / ReadF64Floating-point values.
WriteVarintReadVarintVariable-length unsigned number.
WriteZigZagReadZigZagZigZag signed-number representation.
WriteAdaptiveNumberReadAdaptiveNumberAdaptive numeric representation.
WriteStringRaw(str)ReadStringRaw(len)Raw string bytes. Write and read a length separately.
WriteStringCached(str)ReadStringCached()Paired per-message string-cache encoding.
FlushBits()FlushBits()Align bit state; both ends must agree on alignment.

Writer also exposes EnsureCapacity, Reserve, and GetBuffer; Reader exposes Release. The enclosing serializer manages capacity and lifecycle for converters. Do not finalize or release these borrowed objects. Underscore-prefixed methods are implementation details.

Typed application data#

Application annotation
Luau
type Item = {
    id: string,
    amount: number,
    nickname: string?,
}

local item: Item = { id = "Honey", amount = 3 }
local encoded: Pancakes.SerializedData = Pancakes.SerializeAuto(item)
local decoded = Pancakes.DeserializeAuto(encoded) :: Item

A type assertion is a compile-time promise. Validate external values at runtime before trusting them as Item.
