API reference

Configuration

Every setting in the supplied Settings module, including defaults and wire compatibility requirements.

3 min readRoblox Luau

Configure#

Apply supported runtime overrides. Omitted settings retain their current values.

Signature
Luau
Pancakes.Configure(overrides: {
    poolingEnabled: boolean?,
    writerPoolMaxPerBucket: number?,
    readerPoolMax: number?,
    rleThreshold: number?,
    sortedKeysCacheEnabled: boolean?,
    commonKeys: {string}?,
    patternKeysEnabled: boolean?,
    sortedKeysCacheTrustMode: boolean?,
    stringCacheMinLength: number?,
    schemaValidationEnabled: boolean?,
    strictBoundsChecking: boolean?,
    maxDeclaredCountBytes: number?,
    debugAsserts: boolean?,
}): ()

Each setting is optional. Configure before your first payload. It returns no value and changes the shared module runtime.

Recommended starting configuration
Luau
Pancakes.Configure({
    poolingEnabled = true,
    sortedKeysCacheEnabled = true,
    schemaValidationEnabled = true,
    strictBoundsChecking = true,
    sortedKeysCacheTrustMode = false,
})

GetConfig#

Return a new configuration snapshot. The commonKeys array is cloned as well.

Signature
Luau
Pancakes.GetConfig(): Pancakes.SerializerConfig
Example
Luau
local config: Pancakes.SerializerConfig = Pancakes.GetConfig()
print(config.stringCacheMinLength) -- 16 with supplied defaults

Settings and defaults#

SettingType / defaultEffect
poolingEnabledboolean
true		Reuse Writer and Reader objects. Does not change the wire format.
writerPoolMaxPerBucketnumber
8		Retained Writers per power-of-two capacity bucket. Nonnegative; 0 retains none.
readerPoolMaxnumber
16		Maximum retained Readers. Nonnegative; 0 retains none.
rleThresholdnumber
0.3		Adjacent-repeat ratio for eligible RLE arrays. Range 0…1; codec choice is recorded in the buffer.
sortedKeysCacheEnabledboolean
true		Cache sorted keys and inferred Auto record plans using weak table keys.
commonKeys{string}
{}		Up to 32 unique string keys in a fixed order. Must match between writers and readers.
patternKeysEnabledboolean
false		Probe name1, name2, name3-style table keys. Probing can allocate temporary strings.
sortedKeysCacheTrustModeboolean
false		Unsafe: trust cached key layouts. Values may change, but cached keys must remain identical.
stringCacheMinLengthnumber
16		Minimum byte length for per-message string caching. Nonnegative; must match peers.
schemaValidationEnabledboolean
true		Check missing required Schema fields on writes. Does not validate Auto input or Schema reads.
strictBoundsCheckingboolean
true		Explicit malformed-buffer checks for bounds, counts, references, and enums. Native buffer calls can still throw when disabled.
maxDeclaredCountBytesnumber
1		Legacy compatibility only. Must be at least 1; current decoders use codec-specific bit budgets instead.
debugAssertsboolean
false		Expensive adaptive-number diagnostics. Intended for temporary debugging.

Settings that must match#

Keep both ends in sync

commonKeys and stringCacheMinLength must have identical values on every writer and reader, including the exact common-key order. Do not change them while buffers are in flight.

Pass a fresh array to Configure when setting commonKeys. Do not mutate a supplied array afterward: the runtime retains it, and the reverse map is built during configuration. Configure checks the entry count but does not enforce uniqueness or the string type of every entry.

Unsafe speed tradeoffs#

sortedKeysCacheTrustMode = true trusts a cached table’s key order and layout. Cached values can change, but adding, removing, or replacing keys can omit data or use the wrong layout.

strictBoundsChecking = false skips explicit decoder checks; it does not make malformed buffers safe or prevent all native errors. Keep it true for network input. Schema validation checks required fields on writes; it is not a full input validator.

Legacy configuration#

maxDeclaredCountBytes is retained for compatibility but not consulted by current count guards. Keep its supplied value of 1.
