Getting started

Pancakes

Compact binary serialization for Roblox Luau. Turn your game data into small byte buffers, with automatic encoding or an explicit schema.

Get started Explore the API

Your first buffer#

Start with a table. Pancakes handles the encoding, and gives you a native buffer back.

A round trip
Luau
local data = {
    coins = 1250,
    name = "Pancake",
    equipped = true,
}

local encoded: buffer = Pancakes.SerializeAuto(data)
local decoded = Pancakes.DeserializeAuto(encoded)

print(decoded.coins) -- 1250

No schema to declare. No JSON conversion. Follow the quick start to set up the module and run this in Studio.

Choose how you serialize#

Start with Auto, describe stable records with Schema, or explore local shape tracking with SmartSchemas.

AutoEncode supported values without defining a schema.SchemaDefine a reusable layout with typed field constructors.SmartSchemasLearn repeated shapes within one local instance.

Built for your game data#

CapabilityWhat it gives you
Roblox datatypesVector3, CFrame, Color3, EnumItem, DateTime, and more.
Compact tablesSpecialized codecs for eligible arrays and repeated record shapes.
Custom convertersDefine how a metatable-backed value is written and reconstructed.
Configurable runtimeObject pools, shape caches, and explicit decode bounds checks.
Sending data between client and server?

Use Auto or an explicitly shared Schema. SmartSchemas promotion state is local to the instance that learned it. Read the networking guide.
