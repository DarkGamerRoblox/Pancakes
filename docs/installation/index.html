Getting started

Installation

Add Pancakes to a shared location in your Roblox project, then require it from your scripts.

2 min readRoblox Luau

Before you begin#

This build targets Roblox Luau. It uses Roblox buffers, datatypes, and HttpService. It is not a standalone Lua package. Keep the main module and the matching Settings module together.

Set up in Studio#

  • Create a Packages Folder in ReplicatedStorage.
  • Add a ModuleScript named Pancakes and paste the Pancakes library source into it.
  • Add a child ModuleScript named Settings under Pancakes and paste the supplied runtime configuration into it.
  • Use the same Pancakes build and wire-sensitive settings on every writer and reader.
LocationContents
ReplicatedStorage.Packages.PancakesMain library ModuleScript
ReplicatedStorage.Packages.Pancakes.SettingsRuntime configuration ModuleScript
Require the module
Luau
--!strict
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local Pancakes = require(ReplicatedStorage.Packages.Pancakes)
Settings is a child module

The library calls require(script.Settings). A sibling named Settings will not satisfy that path.

Package managers#

Pancakes is structured for Wally, pesde, and Ember. The package keeps Settings as a child of the main ModuleScript, so the same source layout works across all three managers.

ManagerInstall
WallyPancakes = "darkgamer/pancakes@1.0.0", then wally install
pesdepesde add darkgamer/pancakes
Emberembr add darkgamer/pancakes
Before the first registry release

Confirm the public package scope. The repository scaffold currently uses darkgamer/pancakes consistently across Wally, pesde, Ember, and these docs.

Verify the installation#

Installation check
Luau
--!strict
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local Pancakes = require(ReplicatedStorage.Packages.Pancakes)

local encoded: buffer = Pancakes.SerializeAuto({ message = "Hello!" })
local decoded = Pancakes.DeserializeAuto(encoded)
assert(decoded.message == "Hello!")

Then follow the quick start for a typed payload and an explicit schema.
