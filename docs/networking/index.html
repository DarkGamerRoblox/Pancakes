Networking

Send independent, explicit-schema buffers between server and client.

2 min readRoblox Luau

1. Share the contract#

Place this ModuleScript at ReplicatedStorage.Shared.SnapshotSchema. Both sides require this exact schema. This example uses a RemoteEvent called Snapshot inside ReplicatedStorage.Remotes.

SnapshotSchema.luau
Luau
--!strict
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local Pancakes = require(ReplicatedStorage.Packages.Pancakes)
local Field = Pancakes.Field

local schema: Pancakes.Schema = {
    Field.U32("coins"),
    Field.String("world"),
}

return schema

2. Encode on the server#

Server sender
Luau
--!strict
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local Pancakes = require(ReplicatedStorage.Packages.Pancakes)
local Players = game:GetService("Players")
local schema = require(ReplicatedStorage.Shared.SnapshotSchema)
local remote = ReplicatedStorage.Remotes.Snapshot :: RemoteEvent

local function sendSnapshot(player: Player): ()
    local encoded: buffer = Pancakes.SerializeSchema({
        coins = 1250,
        world = "Greenfields",
    }, schema)
    remote:FireClient(player, encoded)
end

-- Example only: send after your real client-ready handshake.
-- sendSnapshot(player)

Call the sender after your client has connected its listener. Pancakes encodes the payload; your network layer owns readiness, routing, delivery, and rate limits.

3. Decode on the client#

Client receiver
Luau
--!strict
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local Pancakes = require(ReplicatedStorage.Packages.Pancakes)
local schema = require(ReplicatedStorage.Shared.SnapshotSchema)
local remote = ReplicatedStorage.Remotes.Snapshot :: RemoteEvent

type Snapshot = { coins: number, world: string }

remote.OnClientEvent:Connect(function(payload: unknown): ()
    if typeof(payload) ~= "buffer" then
        return
    end

    local ok, decoded = pcall(function(): Snapshot
        return Pancakes.DeserializeSchema(payload, schema) :: Snapshot
    end)
    if not ok then
        warn("Could not decode snapshot:", decoded)
        return
    end

    print(decoded.coins, decoded.world)
end)

Receiving client input#

For client-to-server messages, enforce an application byte limit before decoding, catch decode errors, and validate the result before changing state. Keep bounds checks enabled.

Input boundary
Luau
local MAX_PAYLOAD_BYTES = 8192 -- Example limit; choose for your protocol.

local function decodeRequest(payload: unknown): (boolean, any)
    if typeof(payload) ~= "buffer" then
        return false, "Expected buffer"
    end
    if buffer.len(payload) == 0 or buffer.len(payload) > MAX_PAYLOAD_BYTES then
        return false, "Invalid payload size"
    end
    return pcall(Pancakes.DeserializeAuto, payload)
end

Decoding successfully does not authorize a purchase, item grant, or action. Validate known keys, finite numbers, ranges, IDs, ownership, and rate limits on the server. Do not use client-provided values as authoritative balances.

Keep the wire contract stable#

  • Match the Pancakes build, commonKeys order, and stringCacheMinLength.
  • Share schema definitions, directory mappings, and converter registration order.
  • Configure before sending messages; do not change wire-sensitive settings while buffers are in flight.
  • Use Auto or explicit Schema across client/server instances. Do not use the default SmartSchemas wrapper for this example.
