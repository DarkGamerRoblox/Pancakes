Getting started

Quick start

Serialize a typed record, read it back, and choose a layout for repeated messages.

2 min readRoblox Luau

1. Define your data#

After installing the module, create a Script in ServerScriptService. Keep Luau types next to your application data.

PlayerSnapshot.luau
Luau
--!strict
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local Pancakes = require(ReplicatedStorage.Packages.Pancakes)

type PlayerSnapshot = {
    coins: number,
    name: string,
    equipped: boolean,
}

local snapshot: PlayerSnapshot = {
    coins = 1250,
    name = "Pancake",
    equipped = true,
}

2. Encode and decode#

Auto mode
Luau
local encoded: buffer = Pancakes.SerializeAuto(snapshot)
local decoded = Pancakes.DeserializeAuto(encoded) :: PlayerSnapshot

assert(decoded.coins == snapshot.coins)
print("Payload bytes:", Pancakes.GetSize(encoded))

The type assertion tells Luau what your application expects. It does not perform runtime validation. Auto includes type and layout information so the reader does not need a Field schema.

3. Describe a stable record#

Schema mode
Luau
local Field = Pancakes.Field

local snapshotSchema: Pancakes.Schema = {
    Field.U32("coins"),
    Field.String("name"),
    Field.Boolean("equipped"),
}

local encoded: buffer = Pancakes.SerializeSchema(snapshot, snapshotSchema)
local decoded = Pancakes.DeserializeSchema(encoded, snapshotSchema)
    :: PlayerSnapshot

assert(decoded.name == "Pancake")

Declare the schema once and reuse the same table. The library caches compilation by schema identity. Keep field order, definitions, directories, and settings identical on both sides.
