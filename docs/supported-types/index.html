Supported types

Understand the values Pancakes encodes and the precision tradeoffs of each representation.

2 min readRoblox Luau

Luau values#

ValueBehavior
nilSupported as a root Auto value. Nil table entries are absent in Luau.
booleanDedicated false/true tags; eligible boolean arrays use packed bits.
numberAdaptive numeric representations, including compact integers and floating-point encodings.
stringByte strings, with optional per-message caching for repeated content.
tableArrays, records, dictionaries, and mixed tables; codec selection depends on shape.
Registered custom valuesA converter can reconstruct a metatable-backed value. Ordinary metatables are not preserved.

Functions, threads, and raw buffer values do not have a built-in Auto codec in this build. The serializer returns a buffer, but that does not mean buffers are valid payload fields. Convert raw bytes to a string deliberately if you need to carry them.

Roblox values#

DatatypeRepresentation notes
Vector3Integer components, quantized components, or float32 depending on value; small precision changes are possible.
Vector2Integer components where eligible, otherwise float32.
Vector3int16 / Vector2int16Signed 16-bit components.
CFrameFloat32 position and rotation components, with an eligible look-direction representation.
Color38 bits per color channel. Values are rounded and clamped.
UDim / UDim2Float32 scale and signed 16-bit offset. Keep offsets within −32768…32767.
InstanceName path resolved from game at decode time; no instance cloning.
EnumItemEnum type name and numeric value.
DateTimeUnix timestamp in milliseconds.
BrickColorNumeric BrickColor identifier.
NumberSequenceKeypoint times, values, and envelopes as float32.
ColorSequenceFloat32 keypoint time and 8-bit color channels.
NumberRangeMin and Max as float32.
Use tolerances for spatial values

Do not promise exact equality for quantized colors, vectors, or float32 transforms. Choose a tolerance appropriate to the datatype and the magnitude of your values.

Instance references#

The reader starts at game and resolves each name with FindFirstChild. The full path must exist at decode time. Renames, duplicate sibling names, streaming, and unreplicated descendants make this unsuitable as a durable object identity.

A missing path warns and returns nil for that value. Avoid unresolved Instances inside larger messages: a failed lookup returns early and may leave the remaining path bytes unread. Prefer stable application IDs across streaming or persistence boundaries.

Nil, tables, and identity#

  • An assignment such as data.name = nil removes that key. A serializer cannot preserve an explicitly present nil key.
  • Use Field.Optional for named fields that may be absent.
  • Do not treat a sparse array’s #array as its logical length. Use an explicit count or an array of slot records.
  • Do not serialize cyclic tables. This build is not an object-graph serializer and does not preserve shared table identity.
  • Keep nesting and payload sizes bounded in application code.
