Troubleshooting

Common failures, their causes, and the next thing to check.

2 min readRoblox Luau

Decode errors#

Message or symptomCheck
Unsupported Auto wire revisionPair SerializeAuto with DeserializeAuto and use the same build. SmartSchemas output has an additional tag.
Schema version mismatchMatch field order, types, nested schemas, and the build. Do not mutate a cached schema.
No compiled schema foundThe SmartSchemas reader did not promote that schema itself, or its state was reset. Use explicit shared Schema for independent readers.
DELTA-tagged buffer but no idPass the same ID and consume its full state before dependent deltas.
Declared count exceeds safety budgetThe buffer may be truncated, corrupt, malicious, or read using the wrong codec. Keep bounds checks enabled.
Missing required fieldSupply the named field, or wrap its descriptor with Field.Optional if absence is valid.
Directory is not registeredRegister the directory before compiling or using the schema.
Unsupported typeUse a supported type or register a custom converter. Raw buffers have no built-in Auto field codec.

Values differ after decoding#

  • Colors are quantized to 8-bit channels. Float32 spatial values can change slightly.
  • Instance paths depend on the receiving data model. Prefer application IDs if paths may be missing.
  • Schema serialization omits undeclared keys. Add fields to the schema only as part of a coordinated format change.
  • Nil table entries do not exist in Luau. Use explicit slot records when missing positions matter.
  • Disable trust mode if you change keys on cached tables.

Current build notes#

Text encoding helpers need correction

Source inspection reveals tail/accumulator problems in the Base85 and Base91 helper implementations. Do not rely on them for arbitrary byte round trips in this build. Use raw buffers, or Hex with input validation, until those helpers are fixed and tested.

Field.Custom contributes tostring(customMetatable) to a schema hash. Default table identity strings are not stable across independent VMs. For cross-peer custom values, use a registered Auto converter with consistent registration order, and test the actual peer setup.

Narrow down a failure#

  • Reduce the payload to the smallest value that reproduces the issue.
  • Record the writer and reader function names and the Pancakes build.
  • Compare settings and schema definitions on both sides.
  • Record buffer.len(encoded) and, for a small non-sensitive payload, Pancakes.ToHex(encoded).
  • Keep bounds checking enabled while investigating; do not suppress an error by disabling the guard.
