Write a custom converter

Encode a typed GridPoint value as two signed 16-bit coordinates and restore its metatable.

2 min readRoblox Luau

1. Define the custom value#

Place the following sections in one test Script after requiring Pancakes. A shared class module is a good next step when multiple scripts need the same metatable.

GridPoint type
Luau
--!strict
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local Pancakes = require(ReplicatedStorage.Packages.Pancakes)

local GridPoint = {}
GridPoint.__index = GridPoint

type GridPoint = typeof(setmetatable({} :: {
    x: number,
    y: number,
}, GridPoint))

local function newPoint(x: number, y: number): GridPoint
    return setmetatable({ x = x, y = y }, GridPoint)
end

2. Register matching callbacks#

GridPoint converter
Luau
local function writePoint(writer: Pancakes.Writer, value: any): ()
    local point = value :: GridPoint
    assert(point.x % 1 == 0 and point.x >= -32768 and point.x <= 32767)
    assert(point.y % 1 == 0 and point.y >= -32768 and point.y <= 32767)
    writer:WriteI16(point.x)
    writer:WriteI16(point.y)
end

local function readPoint(reader: Pancakes.Reader): GridPoint
    local x: number = reader:ReadI16()
    local y: number = reader:ReadI16()
    return newPoint(x, y)
end

-- The current API annotates metatables as {any}.
Pancakes.RegisterConverter(GridPoint :: any, writePoint, readPoint)

The fields consume four data bytes before the enclosing Auto tags and converter ID. Reading in a different order would change the value. The validation ensures each coordinate fits its chosen representation.

3. Round-trip with Auto#

Preserve the custom type
Luau
local original: GridPoint = newPoint(12, -8)
local encoded: buffer = Pancakes.SerializeAuto(original)
local decoded = Pancakes.DeserializeAuto(encoded) :: GridPoint

assert(decoded.x == original.x)
assert(decoded.y == original.y)
assert(getmetatable(decoded) == GridPoint)

4. Use a custom field locally#

Local custom schema
Luau
local schema: Pancakes.Schema = {
    Pancakes.Field.Custom("position", GridPoint :: any),
}

local encoded: buffer = Pancakes.SerializeSchema({
    position = newPoint(3, 7),
}, schema)
local decoded = Pancakes.DeserializeSchema(encoded, schema)
assert(decoded.position.x == 3)
Register before compilation

Keep registrations deterministic across peers. Custom schema hashes currently depend on metatable string identity, so use the Auto converter path for independent VMs and review the Field.Custom caveat.
