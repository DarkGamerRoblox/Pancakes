Serialize an inventory

Build a reusable schema for an inventory with item IDs, amounts, and optional nicknames.

2 min readRoblox Luau

1. Define the records#

This example encodes a complete inventory snapshot. It does not change your inventory storage model or add replication.

Inventory types
Luau
--!strict
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local Pancakes = require(ReplicatedStorage.Packages.Pancakes)
local Field = Pancakes.Field

type Item = {
    uid: string,
    id: string,
    amount: number,
    nickname: string?,
}

type Inventory = {
    coins: number,
    items: {Item},
}

2. Build a nested schema#

Shared inventory schema
Luau
local itemSchema: Pancakes.Schema = {
    Field.String("uid"),
    Field.String("id"),
    Field.U32("amount"),
    Field.Optional(Field.String("nickname")),
}

local inventorySchema: Pancakes.Schema = {
    Field.U32("coins"),
    Field.Array("items", Field.Table("", itemSchema)),
}

uid distinguishes a stored entry; id identifies its item type. U32 is appropriate here only because the example amounts fit 0…4294967295. For arbitrary-precision currencies, define and test a converter instead of casting a big-number object to number.

3. Write and read the snapshot#

Inventory round trip
Luau
local inventory: Inventory = {
    coins = 1250,
    items = {
        { uid = "item-a", id = "Honey", amount = 12 },
        { uid = "item-b", id = "Wax", amount = 4, nickname = "Keep" },
    },
}

local encoded: buffer = Pancakes.SerializeSchema(inventory, inventorySchema)
local decoded = Pancakes.DeserializeSchema(encoded, inventorySchema)
    :: Inventory

assert(decoded.coins == 1250)
assert(decoded.items[1].nickname == nil)
assert(decoded.items[2].nickname == "Keep")
print("Inventory bytes:", buffer.len(encoded))

4. Adapt a UID-keyed inventory#

If your application stores entries by UID, preserve that shape with a dictionary. You do not need to convert it to an array first.

Dictionary variant
Luau
local keyedItemSchema: Pancakes.Schema = {
    Field.String("id"),
    Field.U32("amount"),
}
local keyedInventorySchema: Pancakes.Schema = {
    Field.Dictionary("items", Field.Table("", keyedItemSchema)),
}

local encoded: buffer = Pancakes.SerializeSchema({
    items = {
        ["item-a"] = { id = "Honey", amount = 12 },
        ["item-b"] = { id = "Wax", amount = 4 },
    },
}, keyedInventorySchema)

5. Compact stable item names#

For a fixed shared catalog, register a directory and replace the item’s Field.String("id") with Field.Directory("id", "Items"). Keep numeric IDs stable across updates.

Keep the schema shared

When sending this snapshot over the network, both peers require the same module and configuration. Follow the networking guide for the transport boundary.
