Handle optional values

Distinguish missing values from false, zero, and empty strings, without relying on sparse array lengths.

2 min readRoblox Luau

1. Round-trip a root nil#

Root nil
Luau
--!strict
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local Pancakes = require(ReplicatedStorage.Packages.Pancakes)

local encoded: buffer = Pancakes.SerializeAuto(nil)
local decoded = Pancakes.DeserializeAuto(encoded)
assert(decoded == nil)

The returned encoded buffer is still a value. When calling a decoder through pcall, a successful decode of nil is different from a failed decode: check the success boolean.

2. Declare optional record fields#

Absent, empty, false, and zero
Luau
local Field = Pancakes.Field
local schema: Pancakes.Schema = {
    Field.String("id"),
    Field.Optional(Field.String("nickname")),
    Field.Boolean("locked"),
    Field.U32("amount"),
}

local cases = {
    { id = "Honey", locked = false, amount = 0 },
    { id = "Wax", nickname = "", locked = true, amount = 2 },
}

for _, item in cases do
    local encoded: buffer = Pancakes.SerializeSchema(item, schema)
    local decoded = Pancakes.DeserializeSchema(encoded, schema)
    assert(decoded.nickname == item.nickname)
    assert(decoded.locked == item.locked)
    assert(decoded.amount == item.amount)
end

An absent nickname is nil. An empty nickname is still a string. False and zero remain actual values. Do not test required values with a truthiness shortcut when false is valid.

3. Preserve empty slots explicitly#

A table literal such as {"Honey", nil, "Wax"} has a hole. Its length does not provide a reliable logical slot count. Use a dense array of records whose value is optional.

Dense slot records
Luau
local slotSchema: Pancakes.Schema = {
    Field.Optional(Field.String("id")),
}
local schema: Pancakes.Schema = {
    Field.Array("slots", Field.Table("", slotSchema)),
}

local data = {
    slots = {
        { id = "Honey" },
        {}, -- A present slot with no item.
        { id = "Wax" },
    },
}

local encoded: buffer = Pancakes.SerializeSchema(data, schema)
local decoded = Pancakes.DeserializeSchema(encoded, schema)
assert(#decoded.slots == 3)
assert(decoded.slots[2].id == nil)
assert(decoded.slots[3].id == "Wax")

What to verify#

  • Root nil returns nil without throwing.
  • An absent optional field remains absent.
  • False, 0, and "" survive without being mistaken for absence.
  • Your own explicit slot representation preserves both order and logical length.
  • Required fields still fail when omitted with schema validation enabled.
